# Lidarr 4.0.0.5247-ai.31

Artist pages now have a **Search Unsatisfied** button next to the magnifying glass in each release-type section. It searches monitored releases in that section for missing tracks or quality below cutoff. The artist toolbar still offers a search across all release types.

Load the Linux amd64 archive with `docker load -i lidarr-ai-4.0.0.5247-ai.31-amd64.tar.gz` and recreate the container with `lidarr-ai:4.0.0.5247-ai.31` using your existing appdata and volume mappings.

For upgrades from before ai.30, see the [4.0 migration notes](4.0-ai.30.md).
