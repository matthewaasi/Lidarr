# Lidarr 3.2.1.5196-ai.27

Bulk **Preview Rename** now uses Lidarr's **Organize & Rename** layout with the naming pattern, separate old and new path lines, and file checkboxes. Review changes grouped by artist and uncheck any files you want to skip before clicking **Organize**.

Load the Linux amd64 archive with `docker load -i lidarr-ai-3.2.1.5196-ai.27-amd64.tar.gz`, then recreate your container with `lidarr-ai:3.2.1.5196-ai.27` and your existing appdata, database and volume mappings.
