# Lidarr 4.0.0.5247-ai.30 migration candidate

Integrates upstream Lidarr 4.0.0.5247 (commit `723792986951fb35b8658a5a7804a5d6014aef1d`) into the ai.29 fork. The Linux amd64 Docker image uses .NET 10 and the upstream Chromaprint package for audio fingerprints.

Load the archive with `docker load -i lidarr-ai-4.0.0.5247-ai.30-amd64.tar.gz` and test `lidarr-ai:4.0.0.5247-ai.30` with a copy of your existing appdata and database before migrating the live container. PostgreSQL installations require version 15 or later. Keep the ai.29 image and a pre-upgrade copy of both appdata and any external database for rollback.
