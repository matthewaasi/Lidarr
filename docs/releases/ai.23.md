# Lidarr 3.2.1.5196-ai.23

**Retry Automatic Import** processes the checked rows, or all currently unmapped files when no rows are checked. Task progress reports how many files imported. Debug logs record why individual files were skipped or rejected.

Load the attached Linux amd64 image with `docker load -i lidarr-ai-3.2.1.5196-ai.23-amd64.tar.gz`, then recreate your container with `lidarr-ai:3.2.1.5196-ai.23` and your existing appdata, database, and volume mappings.
